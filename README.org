#+TITLE: Loki Assistant

* 项目简介

Loki Assistant 是个人使用的助理程序。当前重新设计的第一步由 Rust services 和一个最小 macOS 菜单栏入口组成。

* 当前阶段

services 提供本机 loopback HTTP 服务、服务发现、配置数据和 macOS LaunchAgent 管理。Mac 菜单栏应用只展示 services 的健康状态、版本和运行时间，作为后续功能的入口。

~emacs/~ 中已初始化 ~loki-assistant~ Emacs Lisp 包，目前提供包入口和配置组，后续集成能力尚未实现。

* 快速开始

构建并运行 services：

#+begin_src sh
make services-test
make services-run
#+end_src

构建并运行 Mac 菜单栏入口：

#+begin_src sh
make build
make run
make restart-center
#+end_src

修改菜单栏 App 代码后使用 ~make restart-center~，该命令会退出旧进程并强制启动新构建的 App；只执行 ~make run~ 可能会复用旧实例。

构建并运行通用配置编辑器：

#+begin_src sh
make build-config-editor
make run-config-editor
#+end_src

注册、启动和停止 services 用户级 LaunchAgent：

#+begin_src sh
make install-service
make start-service
make service-status
make stop-service
#+end_src

* 开发操作

加载 Emacs 包前，需有正在运行且已启动 ~server-start~ 的 Emacs。从仓库根目录执行：

#+begin_src sh
make emacs-load
#+end_src

该命令通过 ~emacsclient --eval~ 将 ~emacs/~ 加入 ~load-path~，卸载已加载的包后执行 ~(require 'loki-assistant)~ ，用于首次加载和修改后的重新加载。

| 命令 | 操作 |
|------+------|
| make configure | 生成 Mac 菜单栏应用 Xcode 工程 |
| make build | 构建 Mac 菜单栏应用 |
| make run | 启动 Mac 菜单栏应用 |
| make test | 执行 Mac XCTest 和 services Rust 测试 |
| make test-mac | 执行 Mac XCTest |
| make build-config-editor | 构建通用配置编辑器 |
| make test-config-editor | 执行配置编辑器 XCTest |
| make run-config-editor | 启动通用配置编辑器 |
| make services-test | 执行 services workspace 测试 |
| make services-fmt | 检查 services Rust 格式 |
| make services-run | 运行 services |
| make install-service | 注册 services LaunchAgent |
| make uninstall-service | 取消注册 services LaunchAgent |
| make start-service | 启动 services LaunchAgent |
| make stop-service | 停止 services LaunchAgent |
| make restart-service | 重启 services LaunchAgent |
| make service-status | 查询 services LaunchAgent 状态 |
| make emacs-load | 通过 emacsclient 重新加载 Emacs 包 |
| make clean | 清理构建产物 |
