#+TITLE: Loki Assistant

* 项目简介

个人使用的助理程序，为手机与电脑协同工作提供支持。

* 当前阶段

项目已实现 Mac 菜单栏应用、连接配置、Emacs 插件入口和连接检查，并建立了控制中心 Rust 服务层骨架及服务发现接口。真实通信的验证范围与结果见 [[file:docs/agent-shell-control.org][第一阶段设计]]；服务层边界与进度见 [[file:docs/control-center-services.org][控制中心 services 模块规划]]。

菜单栏弹出框作为只读状态仪表盘，显示 Emacs 连接、会话数量及更新时间。独立会话窗口支持搜索、状态筛选、刷新、在 Emacs 中打开会话，以及向选定会话发送需求。

第一阶段计划提供 macOS 菜单栏入口，控制本机 Emacs 中的 agent-shell：

- 查看 agent-shell 会话列表。
- 选择会话，在 Emacs 中显示对应 buffer。
- 向指定会话发送需求。
- 提示 Emacs 不可连接、会话失效或发送失败等情况。

Mac 应用使用 SwiftUI 与必要的 AppKit，通过 ~emacsclient --eval~ 调用 Emacs 插件。函数返回值可经标准输出读取，结构化数据使用 JSON，传输细节见控制协议。

* 使用前提

- macOS，已安装并配置可运行的 ~emacsclient~ 。
- Emacs 已启动 server；会话控制需要安装 agent-shell，连接检查不需要。
- 加载本项目的 Emacs 插件，见 [[file:emacs/README.org][插件安装与配置]]。

* 快速开始

1. 按 Emacs 插件说明配置加载路径，在已有 Emacs 中加载插件并启动 server。
2. 在仓库根目录执行 ~make run~ 构建并运行 Mac 应用，详见 [[file:center/README.org][主程序说明]]。
3. 点击菜单栏图标，在设置中确认 emacsclient 路径及 server；重开仪表盘自动检查连接。
4. 点击“打开会话管理”，在独立窗口中选择会话并发送需求；点击“在 Emacs 中打开”可查看完整对话。

连接检查本身不需要安装 agent-shell；后续会话控制需要它。

* 开发操作

根目录 Makefile 是统一入口。需要系统自带的 GNU Make、CMake 3.30 及以上和支持 Swift 6 的 Xcode。

| 命令              | 操作                                      |
|-------------------+-------------------------------------------|
| make help         | 查看可用操作                              |
| make configure    | 生成 Xcode 工程                           |
| make build        | 构建 Mac 应用，默认 Debug                 |
| make run          | 构建并启动 Mac 应用                       |
| make xcode        | 生成并打开 Xcode 工程                     |
| make test         | 执行 Mac XCTest、Emacs ERT 和 services Rust 测试 |
| make test-mac     | 构建并执行 Mac XCTest                     |
| make test-emacs   | 通过已有 Emacs server 执行 ERT            |
| make services-test | 执行 services Rust 测试                  |
| make services-fmt  | 检查 services Rust 格式                  |
| make services-run  | 运行 services 本地服务                  |
| make test-connection | 加载插件并验证真实连接、会话列表与点击激活 |
| make release      | 构建不含测试的 Release 应用               |
| make clean        | 清理当前配置及 Release 产物，保留生成工程 |

~make test~ 需要已有 Emacs server；仅检查 Mac 部分可执行 ~make test-mac~ 。
仅检查服务层可执行 ~make services-test~；运行格式检查可执行 ~make services-fmt~ 。

~make test-connection~ 使用已有 Emacs server，重新加载当前插件源码，在 Mac 应用宿主中检查真实连接、失败恢复、会话列表显示、整行选择与显式打开激活。会话检查需要安装 agent-shell；存在会话时，还会验证重新打开会话窗口后的刷新、选中项及草稿保留，结束后恢复 Emacs 窗口布局。没有会话时跳过点击验证。此入口不启动或退出 Emacs，也不发送需求。普通 ~make test-mac~ 跳过依赖真实 Emacs 的联调检查。

可通过 ~CONFIG~ 选择构建配置，通过 ~BUILD_DIR~ 和 ~RELEASE_BUILD_DIR~ 指定输出目录；工具路径支持 ~CMAKE~ 、 ~CTEST~ 、 ~EMACSCLIENT~ 和 ~OPEN~ 覆盖。~EMACS_SOCKET~ 可为 Emacs 测试及联调指定 server 名称或 socket 路径，留空使用默认 server。例如：

#+begin_src sh
make build CONFIG=Release
make test-emacs EMACSCLIENT=/opt/homebrew/bin/emacsclient
make test-connection EMACSCLIENT=/opt/homebrew/bin/emacsclient EMACS_SOCKET=server
#+end_src
