#+TITLE: Loki Assistant

* 项目简介

Loki Assistant 是个人使用的助理程序，应用中文名称为“Loki的助理”。当前重新设计的第一步由 Rust services 和一个最小 macOS 菜单栏入口组成。

* 当前阶段

services 提供本机 loopback HTTP 服务、服务发现、配置数据、系统通知、Emacs gateway 和 macOS LaunchAgent 管理。Mac 菜单栏应用展示 services 状态并承接系统通知，点击后回调 services 执行对应业务跳转。

~emacs/~ 中的 ~loki-assistant~ Emacs Lisp 包提供服务配置管理、异步 services HTTP 请求与通知发送，支持目标 buffer、标题、正文、应用标识和处理器选择；失败时返回明确错误。

* 快速开始

构建并运行 services：

#+begin_src sh
make services-test
make services-run
#+end_src

构建并运行 Mac 菜单栏入口：

#+begin_src sh
make build
make run
make restart-center
#+end_src

修改菜单栏 App 代码后使用 ~make restart-center~，该命令会退出旧进程并强制启动新构建的 App；只执行 ~make run~ 可能会复用旧实例。

在已启动 server 的 Emacs 中打开服务配置管理界面：

#+begin_src sh
make emacs-config
#+end_src

也可在加载包后执行 ~M-x loki-assistant-config~ ，或通过菜单栏“设置”打开。界面按模块显示配置，提供校验、保存、撤销编辑和文件选择；详见 [[file:docs/emacs.org::*服务配置管理][服务配置管理]]。

注册、启动和停止 services 用户级 LaunchAgent：

#+begin_src sh
make install-service
make start-service
make service-status
make stop-service
#+end_src

* 开发操作

加载 Emacs 包前，需有正在运行且已启动 ~server-start~ 的 Emacs。从仓库根目录执行：

#+begin_src sh
make emacs-load
make emacs-test
#+end_src

该命令通过 ~emacsclient --eval~ 将 ~emacs/~ 加入 ~load-path~，卸载已加载的包后执行 ~(require 'loki-assistant)~ 和 ~(require 'loki-assistant-config)~ ，用于首次加载和修改后的重新加载。

~make emacs-test~ 重新加载包并运行 ERT，使用临时 HTTP listener 验证请求、通知与配置界面，不改动用户配置或发送系统通知。测试失败时命令返回非零退出码；不会退出 Emacs。~make test~ 仍按下表执行 Mac 与 services 检查，Emacs 测试通过独立入口运行。

| 命令 | 操作 |
|------+------|
| make configure | 生成 Mac 菜单栏应用 Xcode 工程 |
| make build | 构建 Mac 菜单栏应用 |
| make run | 启动 Mac 菜单栏应用 |
| make test | 执行 Mac XCTest 和 services Rust 测试 |
| make test-mac | 执行 Mac XCTest |
| make emacs-config | 打开 Emacs 服务配置管理界面 |
| make export-icons | 从 SVG 母版导出应用和菜单栏图标 |
| make services-test | 执行 services workspace 测试 |
| make services-fmt | 检查 services Rust 格式 |
| make services-run | 运行 services |
| make install-service | 注册 services LaunchAgent |
| make uninstall-service | 取消注册 services LaunchAgent |
| make start-service | 启动 services LaunchAgent |
| make stop-service | 停止 services LaunchAgent |
| make restart-service | 重启 services LaunchAgent |
| make service-status | 查询 services LaunchAgent 状态 |
| make emacs-load | 通过 emacsclient 重新加载 Emacs 包 |
| make emacs-test | 通过 emacsclient 执行 Emacs ERT 测试 |
| make clean | 清理构建产物 |
