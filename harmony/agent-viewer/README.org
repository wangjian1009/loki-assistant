#+TITLE: HarmonyOS AI 远程对话

从手机助手的「当前设备」或桌面入口打开 AI 远程对话窗口。电脑在线后，页面优先打开正在执行或等待输入的会话。点击左上角打开侧栏并切换会话，标题栏显示所选会话的标题和状态。窗口与「当前设备」共享已选电脑和状态订阅，正文使用独立的会话 SSE 流。 [[file:../../docs/control-center-services.org][控制中心接口]]

会话按 Emacs Agent Shell 缓冲区的顺序和分组显示。活动组沿用电脑端的初始展开状态，工具输出和思考正文默认折叠为低对比度的标题行。点击标题可展开或收起。普通对话正文直接显示。Org 和 Markdown 共用标题、列表、引用、表格与代码块样式，代码保留换行和缩进。混合正文可以通过标注 ~org~ 或 ~org-mode~ 的 Markdown 围栏明确指定 Org 片段。

打开会话时订阅最近十条记录，点标题栏的「全部」加载完整历史并继续订阅。查看最新内容时，新输出会跟随到末尾。用户和 Agent 的身份标识使用不同颜色。底部输入框支持回车和发送按钮。手机通过 Agent Shell 接口将文本交给 Emacs 中的当前会话。

内嵌图片按电脑和会话缓存，点图可查看大图。普通图片链接在点击时加载。同一会话内重复点击会按原始链接复用本地文件。检测到会话关闭时会取消未完成的图片请求并清理该会话的缓存文件和链接映射。图片由 Emacs 从会话引用读取，支持 PNG、JPEG、GIF 和 WebP，单张最大为 1 MiB。
