#+TITLE: Chrome 插件弹窗交互设计
#+LANGUAGE: zh-CN
#+DATE: 2026-11-19

* 设计状态

本文记录弹窗设计及实施边界。工具在前的导航、按密码框选择默认页、紧凑列表、内页详情、
密码遮罩、TOTP 倒计时、选中项快捷键、密码页连接状态与已接入工具已落到插件。
工具栏匹配数量角标也已实现。工具页已改为独立的四列图标网格，无搜索与密码条目加载；
界面使用 Browserpass 风格中性灰配色。尚未接入的服务能力不展示入口。既有协议与实现边界仍以
[[file:chrome-extension.org][Chrome 插件、密码查询与全文捕获设计]] 为准。

* 核心布局

弹窗依次包含「工具」「密码」「稍后阅读」标签页，网站上下文与密码查询状态在密码页展示。打开弹窗时根据当前页面是否存在密码输入框选择默认页。

** 默认页选择

| 当前页面情况 | 默认页 |
|--------------+--------|
| 有可见、可编辑的密码输入框 | 密码 |
| 没有密码输入框，或只有隐藏、禁用、只读的密码输入框 | 工具 |
| 页面检测失败、页面不支持脚本或 frame 无权访问 | 工具，仍可手动进入密码页 |

判断依据是当前页面的 =input[type=password]= ，与密码库是否存在匹配条目无关。
有密码框但无匹配条目时，仍打开密码页并呈现无匹配状态；普通文章页面即使有匹配条目，
也默认打开工具页。用户名先行、下一步才显示密码的登录页，在当前没有密码框时进入工具页。

检测在用户打开弹窗后使用已有 activeTab 与 scripting 授权，只读取可访问 frame 内
密码框的存在与可用性，不读取输入值，不新增全部网页访问权限。不可访问 frame 的结果
视为未知，不猜测其中是否存在密码框。只要有一个可访问 frame 检测到可用密码框，就进入密码页。

初始检测完成前保持中性加载状态，避免先展示工具再跳到密码。用户手动选择标签后，迟到的
检测结果不得覆盖选择，当前这次打开期间不因页面动态变化强制跳页；下次重新打开再检测。
进入密码页后聚焦密码搜索框；进入工具页后聚焦第一个可用图标。

弹窗宽度为 440 CSS px，高度随内容变化，最大 580 CSS px，适配 Chrome 弹窗的高度限制。
列表与详情的中间内容区独立滚动，标题、导航和操作反馈保留。详情替换密码列表，返回时
恢复搜索、过滤、选中位置和滚动位置，不在小弹窗里叠加模态对话框。

** 顶部与网站上下文

- 顶部显示现有 Loki 图标与产品名。仅密码页显示“服务已连接 / 正在连接 / 服务未连接”。连接成功
  必须来自真实请求结果；点击状态打开轻量诊断，失败时提供重试，保留搜索输入。
- 密码页网站上下文显示当前完整 hostname，例如 =id1.cloud.huawei.com= 。长域名省略显示，
  完整值通过可聚焦元素的说明暴露；不显示 URL 中的查询参数或令牌。
- “密码”旁的数字只表示当前网站的匹配数量，不随搜索词变化；搜索结果数量单独显示。
  工具页导航显示「工具」「密码」「稍后阅读」。密码匹配数字、网站上下文、连接状态和查询反馈在密码页显示。
- 图标角标同样只表示当前网站匹配数量。无匹配时留空，查询失败不得伪装成 0。

* 密码界面

搜索框内部左侧放置可移除的“当前网站”过滤标签，右侧输入搜索词。移除标签或在
空输入框按 Backspace 后切换到全部条目；明确提供“全部条目”入口，并能恢复当前网站。
进入密码页时聚焦搜索框，沿用现有第一词模糊匹配、其余词字面过滤规则。

华为示例中，网站上下文为 =id1.cloud.huawei.com= ，匹配条目为 =huawei.com.gpg= 。
主标题显示 =huawei.com= ，次行显示配置的密码库名称与条目相对路径，避免把密码库名
误当成用户名。列表查询只返回文件名，因此首页不额外解密获取用户名、OTP 或使用记录。
匹配解释“匹配父域名 huawei.com”帮助理解两处域名不同的原因；只接受 hostname 相等或
以点号分隔的子域匹配，=huawei.com.evil.example= 不得命中。

整行主区域用于填充，右侧固定三个操作：复制用户名、复制密码、查看详情。图标使用
统一线条，并提供 tooltip、aria-label 和清晰的键盘焦点。操作区域互不覆盖。

只有一条记录时保持紧凑，不用无内容的固定高度填满画面。底部操作提示随当前页面和
焦点变化；成功复制显示具体字段名称，失败显示可重试原因，不在反馈中暴露密码。

** 键盘行为

| 输入 | 拟定行为 |
|------+----------|
| 上 / 下 | 在结果中移动选中项，滚动保持选中项可见 |
| Enter | 填充选中项；尚未选择时填充第一项 |
| Ctrl+C | 搜索框无文本选区时复制选中条目的密码 |
| Ctrl+Shift+C | 搜索框无文本选区时复制选中条目的用户名 |
| Ctrl+O | 打开选中项详情 |
| Backspace | 搜索框为空且限定当前网站时，移除网站过滤 |
| Esc | 先退出详情或内联诊断；在首页交还 Chrome 的关闭行为 |
| Ctrl+Shift+F | 沿用已有扩展命令，填充当前网站最匹配条目 |

不拦截 macOS 的 Cmd+C 原生文本复制。选中项模型与文本选区判断已在插件中实现；
实现使用现有扩展命令，不额外安装全局快捷键。

* 条目详情

详情页保留网站上下文，头部提供返回；展示条目名称、密码库及相对路径。
首次进入时按需解密。用户名和 URL 单独成行并提供相应动作，密码默认遮罩，只有点击
显示才出现明文。额外字段逐一正确复制其自身值，不回落为复制用户名。

带 OTP 的条目才展示 OTP 区域，显示当前 token、有效期和复制动作；不支持的类型给出
明确提示。只展示当前条目实际存在的字段。
主要按钮为“填充当前页面”，次要动作为“打开条目网址”；没有 URL 时隐藏打开入口。
填充行为继续尊重现有 autosubmit 设置，带 OTP 的条目沿用填充后复制 token 的行为。

* 工具页与能力扩展

工具页独立设计为手机桌面式图标网格，不提供搜索框。每行 4 个功能，使用约 50 px 的
圆角图标容器和下方 12 px 短名称，单项约 94 px 高；只在悬停说明中展开用途，不为每个
功能铺设长说明或占满一行的大按钮。内容超出高度时滚动，功能数量较少时保持紧凑。

「全文保存」将当前页面转换为 Org 并交给 Emacs。「保存链接」将当前网页的标题和地址加入稍后阅读，两项操作都在图标下方显示结果。

工具页打开时只读取默认页判断和工具所需的页面上下文，不主动查询密码条目，也不等待
密码服务。密码列表在首次进入密码页时按需加载；加载中重复进入不重复请求，加载完成后
同一次弹窗内切回密码页复用已有列表，可通过密码页连接诊断手动重试。
后台工具栏角标继续独立刷新，不把条目列表传入工具页，也不因此触发 popup 的条目查询。

全文保存进行中禁用自身图标，防止重复提交。
工具执行结果仅显示在工具网格下方，不混入密码状态；用户在密码查询未完成时切回工具页，
迟到的密码响应也不能把计数、错误或列表显示到工具页。

其他工具在后续设计确认、能力接入后追加网格图标，不提前确定功能或展示占位图标。
每项能力保持独立功能目录，不把协议和业务集中到 popup。

全文保存请求发起后显示进行中并防止重复提交；HTTP 202 显示“已在 Emacs 打开捕获，
请确认保存”，不能显示“已保存”。已存在的来源显示“已打开已有文档”，超时显示结果未知，
不自动重试。详情沿用已有协议，不在这里新增服务端接口。

* Browserpass 能力承载

| 能力 | 拟定位置 | 状态与约束 |
|------+----------+------------|
| 域名过滤、搜索、复制、填充 | 密码首页 | 已有基础能力，调整呈现 |
| 字段详情、URL、OTP | 条目详情 | 已有基础能力，调整呈现 |
| 数字角标 | 图标 | 已实现，与弹窗入口使用相同域名匹配规则 |
| 选中项键盘导航 | 密码列表 | 已实现 |
| 最近使用、历史 | 后续列表排序或筛选 | 当前未记录，不展示虚构时间 |
| 多密码库 | 搜索过滤与条目次行 | 当前单库；未来协议支持后再增加切换 |
| 新增、编辑、删除、密码生成 | 密码页新增入口与详情更多菜单 | 当前只读，不展示操作；服务端写入能力接入后开放 |
| Basic Auth | 独立的认证响应流程 | 当前未实现，需要单独评审权限与协议 |
| 服务配置 | 本机应用与既有配置管理 | 不新增扩展端口、token 或 Native Messaging 设置页 |

新增入口可以放在密码页列表标题右侧；编辑、删除放在详情更多菜单，不挤占逐行高频操作。
新增与编辑进入同一个弹窗内的表单页，提交成功后回到列表；删除需要就地确认，写入失败
保留用户输入。这些均为未来交互设计，不暗示 services 当前具备写入接口。

** 角标与权限边界

插件增加 =tabs= 权限，在用户点击扩展前读取当前标签页 URL 以更新角标，不增加全部网页访问权限。
原有 activeTab、scripting 与 loopback host permission 保持各自职责。后台只查询密码条目名称并
按 hostname、端口匹配，不解密密码，不注入网页脚本，也不以页面是否存在密码框决定角标数量。

扩展加载、安装、浏览器启动、导航、标签页激活、窗口切换和弹窗重新查询后刷新角标。
新导航先清除旧数字，查询成功且有匹配时显示数量，无匹配时留空，服务失败时清空并用图标提示
说明查询未完成。结果写入前按 tabId、请求代次、最新 URL 与待导航状态校验，丢弃旧页面的结果；
同标签页的角标写入串行执行，关闭标签页时清理请求状态。并发查询只复用进行中的列表请求，完成后不缓存。

* 状态与视觉

| 状态 | 呈现 | 主要动作 |
|------+------|----------|
| 正在查询 | 中性状态与骨架，尚无计数 | 等待，不先显示 0 |
| 当前网站无匹配 | 保留 hostname，显示没有匹配条目 | 查看全部条目 |
| 搜索无结果 | 保留过滤与输入，显示搜索无结果 | 清空搜索或移除过滤 |
| 服务未连接 | 独立错误提示，保留网站与输入 | 重试 |
| Chrome 内部页等不支持页面 | 显示当前页面不支持填充 / 捕获 | 仍允许搜索与复制密码 |
| 正在执行 | 只锁定当前动作，显示具体进度 | 防止重复提交 |
| 复制或填充成功 | 原位轻量反馈，通过 aria-live 宣读 | 可继续操作 |

配色参考 Browserpass：浅色使用 #f1f3f5 背景、#343a40 正文和 #1c7ed6 蓝色高亮；
深色使用 #414141 背景、中性灰容器和 #d79921 琥珀色高亮，跟随系统主题，不再使用墨绿色底色。
品牌图标继续消费公共母版生成的现有资源，普通工具图标采用统一线条。
状态除了颜色还必须有文字，工具图标和密码按钮均可通过键盘聚焦；小按钮至少 32 px。

* 实施顺序与验收

第一步实施工具在前的导航、按密码框选择默认页、搜索标签、紧凑条目、内页详情和真实连接状态，保留已有查询及填充协议。
第二步补齐选中项快捷键、按字段正确复制及遮罩交互，并使用 tabs 权限实现自动角标；这部分已完成。
工具页使用四列图标网格，密码列表在进入密码页时延迟加载。

华为登录页存在可用密码输入框时默认进入密码页，显示实际 hostname 与真实条目匹配结果。
无密码框的页面默认进入工具页；有密码框但无匹配条目仍进入密码页，手动选择不会被迟到检测覆盖。
详情按需解密；密码默认不可见。无匹配、断开 services、只读条目及未支持页面均有准确反馈。
全文保存和保存链接均在 Emacs 保存后显示成功。

* 稍后阅读标签页

每次切入时重新查询，列表项显示标题、「标记已读」和「删除」操作。有网址的条目会显示网址，点击标题可在浏览器新标签页打开。操作成功后刷新未读列表。加载、空列表和失败均用文字提示，提供「刷新列表」入口。 [[file:../design/chrome-plugin/read-later.fig][OpenPencil 设计]]

* 界面实现与验证

界面以实际插件实现为准，不再维护重复的独立 HTML 原型。
布局见 [[file:../chrome-plugin/extension/popup/popup.html][popup.html]]，配色与网格见
[[file:../chrome-plugin/extension/popup/popup.css][popup.css]]，按需查询与视图切换见
[[file:../chrome-plugin/extension/popup/popup.js][popup.js]]。

验证重点为：无密码框的页面打开工具页时不发起 popup 密码查询；进入密码页才加载列表，
工具页显示全文保存和保存链接各自的提交结果。
