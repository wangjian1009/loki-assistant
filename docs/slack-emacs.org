#+TITLE: Emacs 中的 Slack 操作界面
#+SETUPFILE: .setup.org

用户在 Emacs 里打开 Slack 聊天选择界面时，可以先看到需要处理的会话，也可以输入人名或主题名快速定位聊天。 [[file:emacs.org::*Slack 聊天][使用说明]]

* 用户目录

- services 启动后，主动准备并缓存每个已授权工作区的用户目录。用户可在消息输入区使用已准备好的用户名和头像。
- services 提供查询所有已授权工作区完整用户目录的接口。目录覆盖工作区成员，包含用于辨认、搜索和显示头像的资料，并可区分同名用户所属的工作区。
- 用户目录仍在准备或暂不可用时，用户选择器会提示当前状态。

* 候选列表

选择界面使用紧凑布局，搜索输入位于顶部，下方按组显示候选。每个会话占一行，当前候选清晰高亮。用户可以边输入边筛选、用键盘移动候选并回车打开聊天。

Emacs 每次打开列表时从 services 读取一次候选快照，在当前选择界面组织显示、筛选、分组和排序。关闭选择界面后即丢弃这份快照。 [[file:slack-services.org::*会话选择][会话选择接口]]

| 内容         | 界面表现                                                                                                                                                    |
|--------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 聊天名称     | 显示「Team 名 · 聊天名」，频道名带 ~#~ 。有本地头像的私聊在名称左侧显示头像。 |
| 未读状态     | 有未读消息时显示数量。有未读消息直接提到本人时，额外显示「@我」，让用户能同时看到未读总数和提及状态。                                                       |
| 最后一条消息 | 发送者、时间和一行预览分别对齐。线程回复更新时，以时间最新的消息为准。纯附件消息显示附件类型或名称，尚无消息时显示「暂无消息」。 |

* 默认排序

按以下顺序分组，仅显示有候选的分组。

1. *已打开*。有存活聊天 buffer 的会话均显示在这里，按最后一条消息时间从新到旧排序。
2. *未读*。有直接提及的会话优先，按最近一条未读提及时间排序。其余未读会话按最后一条消息时间排序。
3. *其他*。按最后一条消息时间从新到旧排序，暂无消息的聊天排在组尾。

排序时间相同时按显示名称排序。

* 模糊搜索

- 输入内容变化时更新候选。会话名称、用户显示名和 Slack 用户名支持片段匹配和按顺序跳字匹配。例如输入「产论」可以找到「产品讨论」。
- 中文用户名支持按全拼、拼音片段和拼音首字母查找。以「张伟」为例，输入 ~zhangwei~ 、 ~zhang~ 或 ~zw~ 均可找到对应私聊。拉丁字母匹配忽略大小写，用户可以省略声调。
- 搜索结果沿用「已打开」「未读」「其他」的分组顺序。支持按 Team 名搜索。组内完整匹配排在模糊匹配之前，同等匹配程度按默认排序。输入清空后恢复完整候选列表。没有匹配结果时显示「未找到匹配的聊天」。

* 按用户打开私聊

在消息输入区的行首或空白后键入 ~@~ 会打开 Consult 用户选择器。Emacs 通过 ~GET /slack/users~ 一次读取工作区用户目录，并从 Emacs 自带的拼音字典构建候选。可按姓名、Slack 用户名、Team 名、全拼、拼音片段或首字母筛选。用户候选显示工作区、姓名、用户名及已缓存的头像，同名候选可通过工作区或用户 ID 区分。

选中用户后，按 ~Shift+Enter~ 打开私聊并保留原草稿。已有私聊窗口会重新获得焦点。按 ~RET~ 将 ~@用户名~ 作为文本插入草稿，按 ~C-g~ 退出选择并保留键入的 ~@~ 。Emacs 在本次运行期间保留通过 ~@~ 打开私聊的最近 100 位用户。同等匹配程度下，越近期打开的用户越靠前。 [[file:slack-services.org::*按用户打开私聊][私聊接口]] · [[file:../design/emacs/slack.fig][OpenPencil 界面稿]]

* 在聊天中设置昵称

聊天和线程的标题栏显示 ~C-c n 设置昵称~ 。在 ~@姓名~ 上按快捷键选中被提及的人，在消息的其他位置按快捷键选中发送者。输入区中的单人私聊默认选择对方，频道和群聊会打开 Slack 用户选择器。

minibuffer 显示目标用户及所属工作区，并预填已保存的昵称。 ~RET~ 保存，留空提交恢复 Slack 显示名， ~C-g~ 取消。services 持久化昵称后通过会话订阅刷新已打开的聊天，光标和草稿保留。 [[file:slack-services.org::*设置本机昵称][昵称接口]]

* 聊天窗口

选择会话后打开聊天窗口。再次选择同一会话时，回到已有窗口。窗口显示聊天时间线和消息输入区。

聊天窗口标题显示「Team 名 · 聊天名」，buffer 名形如 ~*Slack Team 名 · 聊天名*~ 。菜单栏的「Slack 聊天」打开最近使用的聊天，当前没有打开的聊天时显示聊天选择器。

连续来自同一 Slack 用户的消息共用一个单独成行的姓名色块。头像可用时，显示在色块内的姓名左侧。正文缩进并按消息留出段落间距。本人消息和输入区均使用「我」色块，输入提示符为 ~❯~ 。消息末尾的灰底色块按本地时间显示「今天」「昨天」、今年的月日或跨年的年月日，并附上时分。使用 ~n~ 或 ~p~ 可逐条移动，也可移动到链接、附件、线程或翻页按钮。

带线程的消息左侧显示折叠箭头，默认展开回复。点击消息正文或箭头，也可以将光标移到消息上按 ~RET~ ，即可折叠或重新展开。刷新会保留手动折叠的状态。回复按时间排列。

前台聊天窗口显示到消息末尾时，Emacs 会推进相应的本机已读位置。主聊天的顶层消息和每条线程的回复各自记录已读位置。折叠的回复保留未读，展开或进入线程后随显示推进。

在根消息或任一已展开的回复上按 ~S-Enter~ ，可在当前窗口打开独立的线程 buffer。buffer 名称和标题保留主会话名称，并在后面追加根消息摘要。摘要过长时显示「...」。在输入区按同一快捷键可插入换行。按 ~RET~ 发送回复后，主聊天中的对应线程会自动更新。在线程历史中按 ~q~ 返回主聊天，再次打开同一线程时会保留草稿。按 ~C-c C-q~ 可关闭当前聊天或线程 buffer。

链接和附件使用 Emacs 文本按钮，表格按列排版。图片附件在正文下方显示预览。

顶层消息和线程回复共用会话订阅。同一批推送同时更新主聊天和独立线程。services 重启且 Slack 工作区授权恢复后，可在原聊天 buffer 按 ~C-c C-r~ 恢复订阅并刷新消息，草稿仍保留在输入区。 [[file:slack-services.org::*聊天 buffer 刷新][刷新与订阅恢复协议]]

* 从通知打开会话

点击 Slack 通知后，打开对应聊天。聊天已打开时聚焦原窗口。若通知指向线程回复，展开对应线程并定位到回复。回复不可用时定位到根消息，根消息也不可用时打开对应会话。 [[file:slack-services.org::*通知点击跳转][通知跳转接口]]

* 主题聊天关注
:PROPERTIES:
:CUSTOM_ID: conversation-watches
:END:

打开主题聊天时，Emacs 异步读取 ~GET /slack/conversations/{id}/watch~ ，在标题尾部显示「已关注」或「未关注」。以下操作适用于主题聊天主窗口的消息区和输入区。 [[file:slack-services.org::#conversation-watches][主题聊天关注接口]] · [[file:../design/emacs/slack-watches.fig][OpenPencil 界面稿]]

| 操作 | 键盘入口 | 成功反馈 |
|------+----------+----------|
| 增加关注 | 标题显示「未关注」时按 ~C-c C-w~ ，或执行 ~M-x loki-assistant-slack-watch~ 。 | 标题改为「已关注」，回显区提示「已关注 #产品讨论」。 |
| 取消关注 | 标题显示「已关注」时按 ~C-c C-w~ ，或执行 ~M-x loki-assistant-slack-unwatch~ 。 | 标题改为「未关注」，回显区提示「已取消关注 #产品讨论」。 |

增加与取消分别向 ~PUT /slack/conversations/{id}/watch~ 提交 ~watching: true~ 与 ~watching: false~ 。Emacs 收到成功响应后更新标题，保留草稿、光标和滚动位置。提交期间在回显区显示「正在关注…」或「正在取消关注…」，合并重复按键。读取失败时标题显示「关注状态未知」，按切换键先重新查询。提交失败时显示 services 返回的中文说明，结果未知时重新查询后再允许切换。

关注后，主题聊天里的普通新消息和线索回复都会触发提醒。点击通知沿用现有导航流程，聚焦主题聊天，并在需要时展开线索、定位到新回复。 [[file:slack-emacs.org::*从通知打开会话][从通知打开会话]]
