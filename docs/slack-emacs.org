#+TITLE: Emacs 中的 Slack 操作界面
#+SETUPFILE: .setup.org

用户在 Emacs 里打开 Slack 聊天选择界面时，可以先看到需要处理的会话，也可以输入人名或主题名快速定位聊天。 [[file:emacs.org::*Slack 聊天][使用说明]]

* 用户目录

- services 启动后，主动准备并缓存每个已授权工作区的用户目录。用户首次打开聊天选择界面时即可使用已准备好的用户名和头像。
- services 提供查询所有已授权工作区完整用户目录的接口。目录覆盖工作区成员，包含用于辨认、搜索和显示头像的资料，并可区分同名用户所属的工作区。
- 用户目录仍在准备或暂不可用时，界面应说明当前状态，并允许用户继续选择已能显示的聊天。

* 候选列表

选择界面使用紧凑布局，搜索输入位于顶部，下方按组显示候选。每个会话占一行，当前候选清晰高亮。用户可以边输入边筛选、用键盘移动候选并回车打开聊天。

Emacs 每次打开列表时从 services 读取一次候选快照，在当前选择界面组织显示、筛选、分组和排序。关闭选择界面后即丢弃这份快照。 [[file:slack-services.org::*会话选择][会话选择接口]]

| 内容         | 界面表现                                                                                                                                                    |
|--------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 类型与名称   | 明确标出「私聊」或「主题聊天」。私聊显示对方头像和显示名，群组私聊显示参与者头像和群组名称。主题聊天显示主题名，例如 ~#产品讨论~ 。头像缺失时显示占位头像。 |
| 工作区       | 同时显示多个工作区的聊天时，候选标明所属工作区，便于区分同名用户和主题。                                                                                    |
| 未读状态     | 有未读消息时显示数量。有未读消息直接提到本人时，额外显示「@我」，让用户能同时看到未读总数和提及状态。                                                       |
| 最后一条消息 | 显示发送者、时间和一行预览。线程回复更新时，以时间最新的消息为准。纯附件消息显示附件类型或名称，尚无消息时显示「暂无消息」。                                |

* 默认排序

按以下顺序分组，仅显示有候选的分组。

1. *未读 @我*。有未读消息直接提到本人的会话优先，按最近一条未读提及的时间从新到旧排序。会话和线程中的直接提及都计入。
2. *其他未读*。按最后一条消息的时间从新到旧排序。
3. *其余聊天*。按最后一条消息的时间从新到旧排序，暂无消息的聊天排在组尾。

排序时间相同时按会话名称排序，同名再按工作区名称排序。

* 模糊搜索

- 输入内容变化时更新候选。会话名称、用户显示名和 Slack 用户名支持片段匹配和按顺序跳字匹配。例如输入「产论」可以找到「产品讨论」。
- 中文用户名支持按全拼、拼音片段和拼音首字母查找。以「张伟」为例，输入 ~zhangwei~ 、 ~zhang~ 或 ~zw~ 均可找到对应私聊。拉丁字母匹配忽略大小写，用户可以省略声调。
- 搜索结果沿用「未读 @我」「其他未读」「其余聊天」的分组顺序。组内完整匹配排在模糊匹配之前，同等匹配程度按默认排序。输入清空后恢复完整候选列表。没有匹配结果时显示「未找到匹配的聊天」。

* 聊天窗口

选择会话后打开聊天窗口。再次选择同一会话时，回到已有窗口。窗口显示聊天时间线和消息输入区。

时间线按日期分隔，每条消息先显示发送者头像、名称和时间，再显示正文。链接以可点击的标题显示，表格按列排版，附件显示文件名和可用的大小。Slack 图片在正文下方显示预览，预览失败时仍可通过附件链接在 Slack 中打开。

有回复的线程默认在根消息下展开，可手动折叠后重新展开。刷新保留用户选择的折叠状态。选择「回复」后，输入区显示「线程回复>」，在同一窗口写下并发送回复。用户可切回主会话的输入区继续发消息。

* 从通知打开会话

点击 Slack 通知后，打开对应聊天。聊天已打开时聚焦原窗口。若通知指向线程回复，展开线程并定位目标消息。目标消息不可用时仍可进入原线程或会话。 [[file:slack-services.org::*通知点击跳转][通知跳转接口]]
