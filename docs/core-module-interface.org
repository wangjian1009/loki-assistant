*** 服务声明示例

SSE 事件数据使用实现 ~Serialize~ 和 ~JsonSchema~ 的 Rust 类型。~SseEvent::EVENT~ 定义事件名。~#[loki_api(sse_event = ...)]~ 根据声明类型返回 ~supports_sse: true~ 和 ~sse_events~ ，其中 ~data_schema~ 描述该事件的 ~data~ 对象，含嵌套类型。普通 API 返回 ~supports_sse: false~ 和空的 ~sse_events~ 。 [[file:../services/src/http/sse.rs][SSE 类型和编码]]

~POST /mail/sync~ 返回 ~202~ 。本机发送 ~Accept: text/event-stream~ ，已绑定设备发送 ~response_mode: "sse"~ ，均收到包含同一数据结构的 ~sync~ 事件。默认 JSON 响应包含任务 ID。 [[file:control-center-services.org::*手动同步与进度][邮件同步响应]]

| 请求                                  | 可用范围 | 接口能力                           |
|---------------------------------------+----------+------------------------------------|
| GET /stats/meta                       | paired   | 读取各模块声明的状态结构。         |
| GET /status                           | paired   | 查询所有可见状态的快照，可通过 SSE 订阅变化。 |
| GET /status/{module_id}               | paired   | 读取指定模块的状态。               |
| GET /status/{module_id}/{key}         | paired   | 读取指定状态项。                   |
| GET /status/{module_id}/{key}/{*path} | paired   | 读取状态项内的对象字段或数组元素。 |

~paired~ 允许本机和已绑定设备调用。绑定设备只能读取 ~remote_access~ 为 ~true~ 的状态项。业务代码通过 Rust 发布状态。~GET /status~ 的 SSE 事件名为 ~status~ ，数据类型为 ~StatusResponse~ 。 [[file:control-center-services.org::*状态中心][状态中心协议]]

Emacs 上报时通过本机 ~POST /emacs/receiver/status~ 调用 ~publish_many_validated~ 。已绑定设备可读取 ~emacs/agent_shell~ 会话状态数组，数组项可包含会话标题 ~title~ 。 [[file:control-center-services.org::*Agent Shell 执行状态][Agent Shell 状态字段与访问范围]]

~GET /agent-shell/sessions/{session_id}/events~ 是 Emacs 模块声明的 ~paired~ SSE 接口。事件名为 ~agent-shell~ ，事件数据通过 ~sse_events~ 公布。设备用状态数组中的原始 buffer 名选择订阅目标，并在请求路径中将名称编码为单一路径段。 ~recent=10~ 覆盖最近十条会话记录，省略 ~recent~ 覆盖完整历史。客户端可用 ~after~ 从同一会话和范围的已应用版本续订，游标失效后接收新快照。 ~snapshot~ 事件可携带 ~snapshot_end_revision~ 标记快照的最后一批。Emacs 通过回环连接向 services 推送快照和增量内容。内容块可携带 ~parent_id~ 和 ~collapsed~ 以传递分组关系与初始展开状态。 [[file:control-center-services.org::*Agent Shell 会话订阅][Agent Shell 会话订阅协议]]

Emacs 模块通过 ~POST /agent-shell/sessions/{session_id}/messages~ 接收会话消息，通过 ~GET /agent-shell/sessions/{session_id}/image~ 读取会话引用的图片。两个接口的访问范围均为 ~paired~ ，会话标识与订阅接口一致。services 通过固定的 Emacs 入口处理这两种操作。消息接口的 HTTP 202 表示 Emacs 已接收消息，由 Agent Shell 按会话状态提交、引导或排队。 [[file:control-center-services.org::*Agent Shell 消息与图片][Agent Shell 消息与图片协议]]
